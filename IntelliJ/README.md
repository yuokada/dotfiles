# IntelliJ IDEA settings

このディレクトリには、互換性維持のためにコードスタイルと配色 XML を保存しています。

## コードスタイル

`codestyles/Airlift.xml` を IntelliJ IDEA の設定画面から import してください。
macOS で手動配置する場合、現在の設定ディレクトリは通常、次の配下です。

```text
~/Library/Application Support/JetBrains/IntelliJIdea*/codestyles/
```

IDE のバージョンごとにディレクトリ名が異なるため、設定画面からの import を推奨します。

## 配色

`colors/` の XML は過去に使用していた配色です。新規環境では JetBrains Marketplace
で保守されているテーマを優先してください。

- [Airlift code style](https://github.com/airlift/codestyle)
